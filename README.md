## 🎓 CS50: Introduction to Computer Science

I completed **CS50: Introduction to Computer Science** by Harvard University in **2025**, following the course through the official **CS50 YouTube lectures**.

This course gave me a strong foundation in computer science and helped me understand programming beyond just learning a language.

### 📚 Topics Covered

- **C Programming** — syntax, memory, pointers, arrays, algorithms
- **Data Structures** — linked lists, hash tables, trees, tries
- **Algorithms** — searching, sorting, recursion, complexity
- **Python** — programming fundamentals and problem solving
- **SQL** — databases, queries, and relational data
- **HTML, CSS & JavaScript** — fundamentals of web development
- **Flask** — building web applications with Python
- **Computational Thinking & Problem Solving**
- **Memory Management & Computer Architecture**

### 🛠️ Skills Gained

- Problem-solving and algorithmic thinking
- Programming in **C and Python**
- Understanding of **data structures and algorithms**
- Debugging and writing efficient code
- Working with databases using **SQL**
- Fundamentals of web development
- Better understanding of how computers work at a lower level
